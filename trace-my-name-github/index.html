How scoring works

Stayed on the path is the share of ink inside the tracing path. Finished the letters is how much of each letter the ink covered. The accuracy score balances the two, so scribbling or tracing only half both score lower. Formation checks that each letter starts at the green dot and that each stroke goes the Zaner-Bloser direction. It does not check stroke order. When formation checks are on, stars use 70% accuracy and 30% formation.
